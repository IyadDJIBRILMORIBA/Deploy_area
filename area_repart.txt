3. Répartition des Tâches Optimisée

👤 Retys (Architecte, Infra & Engine)
Focus : Le "Squelette" et le "Cerveau".
1. Migrations BDD : Crée les tables services, user_services (pour les tokens),
areas (pour les liens), area_logs.
2. Le Contrat (Interface) : Crée l'interface PHP ServiceInterface que Asaph devra
implémenter.
a. Exemple : public function checkTrigger(array $params): bool;
3. L'Engine : Code la commande php artisan area:execute qui :
a. Récupère toutes les AREAs actives.
b. Instancie le bon Service.
c. Vérifie le Trigger -> Si Oui -> Exécute la Réaction.

👤 Méryl (Auth, API Management & Conformité)
Focus : La "Porte d'entrée" et la "Documentation".
1. API Docs : Installe Scramble (package Laravel) ou maintient un Postman à jour
pour le Front. C'est toi qui parles aux équipes Front.
2. Route /about.json : Implémente la logique dynamique (boucle sur les services
disponibles).

3. CRUD Areas : Code les contrôleurs pour Créer/Lister/Supprimer les AREAs
(c'est ce que le Front va appeler).

👤 Asaph (Intégrateur Services & OAuth)
Focus : Les "Muscles" et "Connexions".
1. Service Google Class : Implémente l'interface définie par Retys.
a. Trigger : NewGmailReceived.
b. Reaction : SendEmail.
2. Gestion Token : C'est ta priorité. Quand tu appelles Google, si ça échoue (401),
tu dois utiliser le refresh_token pour en avoir un nouveau et mettre à jour la BDD.
3. Service Timer : Implémente un service "Timer" simple (Action : "Every Minute")
pour permettre à Retys de tester son moteur sans avoir besoin de Google.

5. Pour valider l'Objectif 1.2 (CI/CD) - À faire tout de suite
Copiez ce fichier, il est propre et fonctionnel pour Laravel. Il lance les tests à chaque
push.

Fichier : .github/workflows/laravel.yml
code Yaml
downloadcontent_copy
expand_less
name: Laravel CI
on:
push:
branches: [ "main", "develop" ]
pull_request:
branches: [ "main", "develop" ]
jobs:
laravel-tests:
runs-on: ubuntu-latest
defaults:
run:
working-directory: ./backend-area # <--- IMPORTANT : Adaptez au nom de votre
dossier
steps:
- uses: actions/checkout@v3
- name: Setup PHP
uses: shivammathur/setup-php@v2
with:
php-version: '8.2'
extensions: mbstring, dom, fileinfo, mysql
- name: Copy .env
run: php -r "file_exists('.env') || copy('.env.example', '.env');"
- name: Install Dependencies
run: composer install -q --no-ansi --no-interaction --no-scripts --no-progress -prefer-dist
- name: Generate key
run: php artisan key:generate

- name: Directory Permissions
run: chmod -R 777 storage bootstrap/cache
# On utilise SQLite en mémoire pour les tests CI (c'est plus rapide que de lancer
MariaDB dans GitHub Actions)
- name: Create Database
run: |
mkdir -p database
touch database/database.sqlite
- name: Execute tests (Unit and Feature)
env:
DB_CONNECTION: sqlite
DB_DATABASE: database/database.sqlite
run: php artisan test
Action immédiate : Commitez ce fichier dès maintenant. Dès que le rond vert apparaît
sur GitHub, vous avez validé un point du barème.
